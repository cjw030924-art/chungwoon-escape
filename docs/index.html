게임 설명

스토리

학술제가 끝난 늦은 밤, 청운대학교 건물에 혼자 남았다. 정신을 차려 보니 정문은 굳게 잠겨 있고, 복도 어딘가에서 무언가가 돌아다니는 소리가 들린다. 정문을 열 수 있는 건 각 학과 강의실에 숨겨진 문제의 정답 번호뿐이다.

목표

3층~8층의 12개 학과 강의실(층마다 2개)을 찾아 문제를 풀고, 정답 번호 12개를 모두 더한 값을 1층 정문 키패드에 입력해 탈출하세요. 틀린 번호를 입력하면… 귀신이 기다리고 있어요.

난이도 · 목숨

  • EASY · 목숨 제한 없음
  • HARD · 목숨 ♥ 5개
  • EXTREME · 목숨 ♥ 3개

귀신에게 잡히면 하트가 하나씩 사라지고, 모두 잃으면 시작 화면으로 돌아가요.

생존 팁

  • 반짝이는 문의 강의실에 문제가 있어요. 복도 끝으로 가면 옆 구역으로 이어져요.
  • 귀신에게 쫓기면 복도 아래쪽 캐비닛에 숨으세요.
  • 문제를 틀리면 10초간 잠기고, 귀신이 소리를 듣고 찾아와요.
  • 2층은 문제가 없는 추격 구역이에요. 끝까지 달려서 통과하세요.
